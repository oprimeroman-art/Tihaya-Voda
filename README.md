# Протокол «Тихая вода» / Tihaya Voda

Приватный репозиторий игры на Gagarin Panorama Studio 2.8.

**Состояние:** репозиторий создан, полная загрузка исходников из архива Кодекса ещё не завершена. Локальный ZIP-пакет включает редактируемые исходники движка и игры, скрипты, сценарий, документы, тесты и сборки. Для переноса используется `UPLOAD_TO_GITHUB.cmd` из пакета передачи.

После переноса в репозитории должны появиться `studio/`, `game-project/`, `codex-scripts/`, `game/`, `game-editor/`, `release-snapshots/`, `reports/` и `docs/`.
