# Протокол «Тихая вода» / Tihaya Voda

Исходники психологического хоррора для **Gagarin Panorama Studio 2.8** и рабочая сборка игры, созданная по сценарию «Протокол „Тихая вода“».

## Структура

- `studio/` — **полный редактируемый исходник Gagarin Panorama Studio**, JS-модули, HTML и система событий; сценарий и постановочные документы также входят в исходный пакет.
- `game-project/` — **распакованный проект игры**, панорамы, игровые объекты и ассеты.
- `game/` — готовая браузерная сборка и встроенный архив проекта.
- `game-editor/` — игровой HTML с редактором.
- `codex-scripts/` — исходные Python и JavaScript-скрипты, созданные Кодексом для сборки, интеграции и тестирования.
- `release-snapshots/` — исходные ZIP-артефакты Кодекса, для воспроизводимости.
- `reports/` — результаты тестирования, контрольные сохранения и отчёты.
- `docs/` — сценарии, техническое задание и независимая проверка.

## Запуск

Распакованные браузерные игры: `game/index.html` и `game-editor/index.html`. Для деталей см. `studio/SETUP.md` и `reports/SETUP.md`.

## Ограничения

Графика и видео частично временные. Наличие в репозитории не означает, что все видеоролики и озвучка произведены. Временные профили Chrome не включены.

## Происхождение

Исходные материалы сохранены из переданного пользователем архива сборки Кодекса 25 октября 2026 года. Содержимое не изменено, кроме нормализации структуры, исключения служебных профилей Chromium и добавления документации.
