# B_NORMAL — игровая проверка кухни в существующем движке

Статус: интеграция для QA, НЕ окончательная замена художественной панорамы кухни. Новых игровых проектов, веток, копий и репозиториев нет.

## Запуск
Скачай актуальный game/index.html из существующего Tihaya-Voda. Открой файл локально в Chrome, добавив ?qa-kitchen=1 к его адресу. Пример: file:///.../Tihaya-Voda/game/index.html?qa-kitchen=1

Появится баннер «АРТ-ТЕСТ B_NORMAL». Начни игру и переходи в кухню обычным маршрутом. Вместо старой кухни загрузится встроенный WebP 2048x1024 и обновятся 11 интерактивных зон.

Для сравнения открой тот же game/index.html БЕЗ параметра: вернутся исходная панорама и штатные хотспоты.

## Безопасность
- Встроенный QA запускается только при точном параметре ?qa-kitchen=1.
- Тестовая панорама включена в тот же офлайн HTML, никакие ресурсы с сети не загружаются.
- Во время QA к названию игры добавляется «Kitchen QA», что меняет отпечаток игры и изолирует локальные сохранения. Основные сейвы не затираются.
- game-project/project.json не изменён: файл rooms/B/original.png, порядок комнат и сюжетные события остаются прежними.
- Все 11 тестовых зон построены из реальных объектов кухни. Зона второй тарелки объединяет UV по обе стороны долготы 0/1; существующий game.objectHit поддерживает развертывание через шов.
- Редактор game-editor/index.html не меняется.

## Воспроизводимость
codex-scripts/build_kitchen_preview.py встраивает текущие панораму и UV в одну секцию KITCHEN_QA_PREVIEW_BEGIN/END внутри существующего game/index.html. --check проверяет актуальность. GitHub Actions render-kitchen-360.yml запускает генерацию, сборку QA, тесты и коммит в main.

## Что пока не проверено
Фактическое прохождение Q01/Q04 в настоящем Chrome, вся визуальная постановка зеркальных состояний, удобство мыши и художественное качество. Проект остаётся в статусе ART CANDIDATE, пока ручные игровые проверки не завершены. Это способ оценить кухню В ИГРЕ, а не обещание, что она уже готова к релизу.
