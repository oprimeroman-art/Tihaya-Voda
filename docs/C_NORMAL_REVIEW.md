# C_NORMAL — статус и просмотр 360°

Зарегистрированы три варианта коридора (см. `production/qa/C_NORMAL_candidates.json`). Все — **кандидаты**, не игровые файлы. Третий выглядит наиболее понятной центральной развилкой, но пока не содержит обязательного металлического зеркала для E013 и не прошёл проверку полной сферической геометрии. Формат 1774×887 (2:1) — ниже целевого минимума.

Новый инструмент `production/tools/panorama-review.html` позволяет открыть любое локальное PNG/WebP/JPEG **офлайн**. Он использует 360° сферическую проекцию, близкую к игровому runtime: ЛКМ + перетаскивание — поворот камеры, колесо — FOV, один/два щелчка по объекту — UV/4 угла. Нажми «Копировать UV» для передачи координат в редактор. Проверять полный оборот, пол/потолок, края на yaw≈±π, русские надписи и узнаваемость проходов.

**Не делать:** выдавать автоматически вычисленную среднюю разницу крайних пикселей за свидетельство отсутствия шва; менять существующие `room.objects[].corners` до принятия окончательной панорамы; смешивать концептуальные изображения с готовыми `game-project` ресурсами; создавать отдельные репозитории и новые копии игры.

**Дальше:** сделать подлинный `C_NORMAL` с физическим зеркалом, затем открыть его этим просмотрщиком, откалибровать переходы и хотспоты; после успеха — `B_NORMAL` (нормальная кухня).
