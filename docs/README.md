# Project knowledge base

Start at [the index](INDEX.md), then [project state](ops/PROJECT_STATE.md) and [the latest handoff](ops/HANDOFF.md).
Open relevant documents only: older research and reports are kept intact in the legacy section of the index. New focused docs belong in docs/features or docs/ops and have title, summary and code_paths in YAML frontmatter.

Useful commands:

    python3 scripts/ai_docs.py index
    python3 scripts/ai_docs.py related studio/index.html
    python3 scripts/ai_docs.py check

The Git repository is the common memory for supported coding agents. No always-on bot is claimed to exist.
