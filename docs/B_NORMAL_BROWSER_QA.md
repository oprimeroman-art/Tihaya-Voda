# B_NORMAL — реальный браузерный прогон (25 октября 2026)

Статус: функциональная QA-проверка новой 360°-кухни в существующей игре. Художественный финал **не утверждён**.

## Что фактически проверено в Chromium

В головном Chromium с программным WebGL/SwiftShader открыт настоящий офлайн game/index.html. Сравнены штатный запуск и явный режим ?qa-kitchen=1; штатный по-прежнему использует image/png, QA — image/webp, а ключи сохранений отличаются. Никаких внешних запросов к материалам для работы комнаты не требуется.

После нажатия «Новая игра» закрыт стартовый сюжетный экран. Реальные игровые кнопки позволяют получить бейдж, перейти из жилого модуля A в коридор C, затем в кухню B. Игровой движок и система сценарных событий находятся в комнате B, WebGL-панорама имеет ширину 2048 пикселей. Камера повёрнута на 0°, 90°, 180° и 270°; получены разные реальные изображения экрана, нет исключений JavaScript.

Из нативных игровых хотспотов в комнате B через реальные нажатия мышью открыты:

- TEA_SEQUENCE — чайник. Нажата полная последовательность «вода → нагрев → заварка → разлить». Проверены флаги TEA_DONE=true и сохранение выполненного действия.
- wash_cup — раковина; действие отмечено как выполненное в сценарии.
- read_D01 — записка возле плиты; открыт оригинальный текст документа.
- plate_choice — специальная зона по обе стороны 0°/360° проверена через нативную objectHit; обе стороны попадают, противоположная середина панорамы — нет.

Здесь нет подмены игровой логики тестовыми скриптами: сценарные флаги изменяются теми же UI-событиями, что и в игре. Запуск браузера автоматизирован в studio/verification/kitchen-browser.test.py. Он проверяет как штатный запуск, так и QA режим, и не пишет в пользовательские сохранения вне изолированного профиля браузера.

Команда:

    python -m pip install playwright
    python -m playwright install --with-deps chromium
    python studio/verification/kitchen-browser.test.py

В GitHub Actions добавлен ручной workflow kitchen-browser-qa.yml с той же проверкой. Он **не запускается на каждый коммит**, чтобы не скачивать Chromium зря. Нет дополнительных копий игры или release-архивов.

## Известные ограничения

Графика новой кухни всё ещё похожа на процедурный 3D-макет, а не на фотореалистичную полярную станцию, как требуется арт-библией. Поэтому штатный запуск игры по-прежнему должен сохранять старую панораму; новая остаётся QA-кандидатом.

Не проверены последовательности поздних эпизодов Q04 (включая B_GHOST_MIRROR, отражение призрака и аудио A05), долговременная производительность на целевом ноутбуке и ручной просмотр в обычном Chrome Windows. Они требуют отдельной приёмки. Утверждать 100% готовность релизного арта по этому отчёту нельзя.
