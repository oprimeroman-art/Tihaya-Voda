# B_NORMAL — художественные материалы и 360-геометрия, этап 2

Статус: **геометрический кандидат с улучшенными материалами**, не финальный фотореалистичный ассет.

Этот этап обновляет существующий источник `production/geometry/B_NORMAL/render_kitchen360.py`, а не создаёт вторую кухню или ещё один проект. Количество физических объектов увеличено с 75 до **97**: появились потолочные кабель-каналы, мелкая инженерная фурнитура, банка со специями, текстовые листы на доске и полотенце у мойки.

Улучшения шейдинга: многочастотная детерминированная фактура поверхностей, потёртая металлическая краска, старение в стыках модульных панелей, разводы и затирка на полу, древесные волокна столешницы, более тёплое локальное освещение и холодный отблеск из окна. Всё вычисляется по 3D-координатам материала, поэтому не движется при повороте камеры.

**Важное ограничение:** это всё ещё процедурный низкополигональный макет. Сравнение с фотоконцептом кухни из переписки показывает, что декоративная отделка пока недостаточно реалистична. Не присваивать статус «готово» только на основании 2:1 формата и замкнутого шва.

Выпускается только один путь-кандидат:
`art/candidates/B_B_NORMAL_360_geometry.webp` (2048×1024).
GitHub Actions пересобирает его при изменении исходного генератора. Действующий `game-project/project.json` и игровые HTML-файлы не меняются.

Проверка:
`python production/geometry/B_NORMAL/verify_kitchen.py` — 97 физических элементов, семь неизменных сюжетных UV-центров, тест 512×256 и замыкания.

После выхода из предварительной геометрии: доработать высокодетализированные предметы, наложить согласованные художественные материалы на конкретные плоскости, проверить полный оборот через существующий `production/tools/panorama-review.html`, вручную откалибровать четыре угла каждого интерактивного объекта, пройти Q01/Q04 в браузерной игре.
