# Gameplay delivery

1. Read current project state and handoff.
2. Trace the player's next action, the game's reaction, the consequence, and a meaningful next situation.
3. Implement in the actual runtime; wire navigation without forcing the player to use a development menu.
4. Exercise one end-to-end scenario, preserve save compatibility, and flag known dead ends.
5. Hand off a specific branch, artifact or playable link. Do not claim a build exists unless created.
