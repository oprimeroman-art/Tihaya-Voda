GAGARIN PANORAMA STUDIO 2.8 — RU / EN

RU
1. Распакуйте архив.
2. Откройте index.html в Chrome — без сервера и интернета.
3. Кнопка RU / EN находится рядом с логотипом вверху.
4. Переключение не меняет исходные данные проекта: комнаты, события, переменные и медиа.
5. Названия и тексты, написанные автором игры, остаются его исходным контентом. Встроенный обучающий дом и интерфейс переведены.
6. Чтобы сохранить редактируемый проект, используйте «Сохранить проект» или «Копия ZIP». Кнопка «Собрать игру ZIP» выпускает готовую игру с языковой кнопкой, а также source-project.zip.
7. Дополнительно лежат DEMO_EDITABLE_PROJECT.zip и DEMO_COMPILED_GAME.zip.

EN
1. Extract the ZIP archive.
2. Open index.html in Chrome. No server or internet required.
3. Use the RU / EN button next to the logo in the top toolbar.
4. Switching language does not modify any project data: rooms, events, variables or media.
5. Custom text entered by game authors remains their content, in the language they wrote it. The built-in tutorial and editor UI are translated.
6. Use Save Project / Backup ZIP to preserve editable data. Build Game ZIP exports a standalone game with its own language toggle and embedded source-project.zip.
7. The package also includes DEMO_EDITABLE_PROJECT.zip and DEMO_COMPILED_GAME.zip.

Testing: Chrome headless using in-memory HTML; direct file:// load was blocked by the testing environment's administrator policy. Real offline file launch should be validated on the target Chrome installation.

Source: source/i18n.js and source/i18n-dictionary.json; JSZip license is included in source/.
