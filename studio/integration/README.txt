Редактор запускается без Python. Для воспроизводимой генерации: Python 3 + Pillow, системный шрифт Arial (Windows). Из папки integration выполнить build_content.py, integrate.py, package.py. Результат в build/. Ручные правки adventure.json будут заменены генератором, поэтому после ручного редактирования сохраняйте проект штатными кнопками.
